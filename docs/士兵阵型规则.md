# 士兵阵型规则

## 锚点 vs 主将
- **锚点** = 前排的中心（第1排中间位置）
- **主将** = 军团的正中心（整个阵型的中心）

## 可视化单位计算
- 500兵 = 1个可视化单位
- 最多100个可视化单位（50000兵）

## 阵型扩展规则（从锚点向外扩展）

```
1个:  ○

2个:  ○○

3个:  ○○
      ○

4个:  ○○
      ○○  (2×2)

5个:  ○○○
      ○○

6个:  ○○○
      ○○○  (2×3)

7个:  ○○○
      ○○○
      ○

8个:  ○○○
      ○○○
      ○○

9个:  ○○○
      ○○○
      ○○○  (3×3)

10个: ○○○○
      ○○○
      ○○○
      ○○○  (第一排扩展到4)
```

## 扩展顺序
1. 先形成横排2个
2. 向下扩展形成 2×2
3. 横排扩展到3个
4. 向下扩展形成 3×3
5. 横排扩展到4个
6. 向下扩展形成 4×4
...以此类推

## 主将位置
- 当阵型足够大时（如 3×3），主将在阵型正中心
- 小阵型时主将在合适的中心位置
